# Klearvision — Coming Soon Landing Page

A simple, attractive static landing page for **Klearvision** with:
- "Exciting update to our website coming soon"
- 30-day countdown timer (persists per visitor using localStorage)
- Tagline: **African Language Dubbing, Global Stories, Local Voices**

## Structure
- `index.html` — the landing page
- `assets/klearvision-logo.png` — logo asset

## Quick start
Open `index.html` in your browser.

## Deploy (easy options)
- **GitHub Pages**: push this repo → Settings → Pages → Deploy from branch.
- **Netlify / Vercel**: drag-and-drop the folder or connect the repo.

## Customize
- Change contact email in `index.html`:
  `mailto:hello@klearvision.com`
